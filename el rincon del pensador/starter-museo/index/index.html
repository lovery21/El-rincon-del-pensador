Cinco momentos de la evolución

1. El trazador en pantalla CRT

Limitación: Información solo en datos y texto.

Cambio: Mostrar información en pantalla mediante imágenes.

Impacto: Fácil identificación de patrones visuales.

Ejemplo: Gráficas de Google Analytics.

2. Sketchpad y lápiz óptico

Limitación: Difícil describir objetos complejos con texto.

Cambio: Dibujar directo en pantalla con un lápiz óptico.

Impacto: Mantener relaciones geométricas visualmente.

Ejemplo: Gráficas interactivas deportivas.

3. Vector vs. Raster

Limitación: Comprender estructuras a través de píxeles puros era complejo.

Cambio: Vectores por fórmulas matemáticas y raster por cuadrícula de píxeles.

Impacto: Vectores para formas editables, raster para detalles fotográficos.

Ejemplo: Logotipos SVG (vector) vs. Fotos JPEG (raster).

4. Llegada de la GPU

Limitación: El CPU era lento para gráficos complejos.

Cambio: Procesador dedicado (GPU) para operaciones paralelas.

Impacto: Renderizado rápido, menos latencia.

Ejemplo: Videojuegos 3D y simuladores fluidos.

5. Canvas y WebGL

Limitación: Se requerían plugins externos (como Flash).

Cambio: Gráficos nativos en el navegador con GPU.

Impacto: Visualización interactiva web sin descargas extra.

Ejemplo: Simuladores 3D en la web.

Laboratorio de color

Exp 1 · Cuando desaparece el tono

Predicción: Blanco, negro y gris no tienen "color". Hue dará error o cero.

Observado: Negro, Blanco y Gris tienen Delta 0.

Conclusión: Al ser Delta 0, no hay saturación ni tono (escala de grises).

Exp 2 · Mismo sector, distinta intensidad

Predicción: RGB(128,64,64) será un rojo más brillante.

Observado: Se vuelve un rojo deslavado (ladrillo).

Conclusión: Subir verde y azul "ensucia" el color hacia el gris, bajando saturación.

Exp 3 · Un color intermedio

Predicción: Será celeste o azul claro.

Observado: RGB(64,128,192). HSL: 210°, 50%, 50%.

Conclusión: Azul acero equilibrado entre cian y azul puro.

Corrección conceptual

Antes: Creía que oscurecer/aclarar era sumar blanco o negro al Hex.

Después: Todo depende del Delta. Acercar los canales entre sí da gris; a 0 oscurece; a 255 aclara.

Cambio: Es mejor usar HSL en CSS que RGB para manipular colores dinámicamente.

De la fórmula al algoritmo

Normalización

Dividir RGB entre 255 (proporción 0-1) para matemáticas.

Máx / Mín

Definen el Brillo (V) y la base de la Saturación.

Delta

Resta entre máx y mín. Delta alto = vivo; Delta 0 = gris.

Acromático

Si canales son iguales (Delta=0), se asigna 0° por convención.

Mi función validada

function convertRGBtoHSV(r, g, b) {
  r = r / 255; g = g / 255; b = b / 255;
  let max = Math.max(r, g, b), min = Math.min(r, g, b);
  let delta = max - min, h = 0, s = max !== 0 ? delta / max : 0, v = max;

  if (delta !== 0) {
    if (max === r) h = ((g - b) / delta) % 6;
    else if (max === g) h = (b - r) / delta + 2;
    else h = (r - g) / delta + 4;
    h = Math.round(h * 60);
    if (h < 0) h += 360;
  }
  return { h, s: Math.round(s * 100), v: Math.round(v * 100) };
}

Mi función validada

La función comienza normalizando los valores RGB al dividirlos entre 255 para convertirlos a una escala decimal de 0 a 1, lo que permite encontrar el valor máximo y mínimo entre los tres canales. Con estos datos se calcula el delta (la diferencia entre el máximo y el mínimo), el cual sirve para decidir si el color es acromático; si el delta es cero, significa que es un tono de gris sin saturación. Si hay un delta mayor a cero, la función procede a elegir la fórmula matemática correspondiente según cuál sea el canal máximo (rojo, verde o azul) para calcular la posición exacta del tono en una rueda de 360 grados.

Glosario

1. RGB (Red, Green, Blue)

Modelo que crea colores mezclando luz roja, verde y azul en valores de 0 a 255. Ejemplo: rgb(255, 0, 0) es rojo puro.

2. HSV / HSL

Modelos de color basados en Tono, Saturación y Brillo/Luz, más intuitivos para humanos. Ejemplo: hsl(0, 100%, 50%) también es rojo puro.

3. Normalización

Convertir una escala de números grandes a una proporción de 0 a 1 para facilitar cálculos. Ejemplo: 128 en RGB se vuelve 0.5.

4. Delta

La diferencia exacta entre el valor más alto y el más bajo en un conjunto de datos. Ejemplo: En rgb(100, 50, 0), el delta es 100.

5. Color acromático

Un color sin saturación ni tono definido, compuesto solo de luz y sombra. Ejemplo: Blanco, negro y toda la escala de grises.

6. Rasterizado (Raster)

Imagen digital construida por una cuadrícula de pequeños cuadros de color (píxeles). Ejemplo: Una fotografía tomada con el celular (.JPG).

7. Vectorial

Imagen dibujada en tiempo real mediante fórmulas matemáticas; no se pixela al hacer zoom. Ejemplo: Un logotipo digital en formato .SVG.

8. GPU

Unidad de procesamiento dedicada exclusivamente a calcular y renderizar gráficos a alta velocidad. Ejemplo: La tarjeta gráfica de una consola de videojuegos.

9. Canvas

Un espacio o lienzo en blanco dentro de una página web donde se dibuja usando JavaScript. Ejemplo: Un minijuego interactivo en el navegador.

10. WebGL

Tecnología web que permite al navegador comunicarse con la GPU para mostrar gráficos 3D pesados. Ejemplo: Un mapa 3D interactivo sin tener que descargar programas extra.

Conclusión

Antes pensaba que manipular colores en la web era solo cuestión de adivinar códigos hexadecimales o sumarles luz y sombra directamente. La evidencia del laboratorio de color y el desarrollo del algoritmo HSV cambió mi idea porque ahora entiendo que el color visual es una relación matemática. La saturación depende totalmente de qué tan separados estén los canales RGB (el Delta); si los igualo, el color "muere" y se vuelve gris, sin importar qué tan altos sean los números.
